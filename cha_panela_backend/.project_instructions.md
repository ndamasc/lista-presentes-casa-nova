# Chá de Panela - Pagamentos
- FastAPI, sem banco de dados (decisão do usuário). Mercado Pago Checkout Pro com redirect (conta PF).
- Endpoints: GET /, POST /criar-pagamento, POST /webhook/mercadopago (sempre 200, processa em background), /docs.
- "Comprado" é marcado pelo front via back_urls (?pagamento=aprovado&id=...), não pelo backend.
- Env: MP_ACCESS_TOKEN, EMAIL_TO, EMAIL_FROM, EMAIL_PASSWORD (Gmail SMTP SSL 465). notification_url é enviado automaticamente a partir de APP_ORIGIN (https).
- Textos ao usuário em pt-BR.
